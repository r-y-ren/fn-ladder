# fn-exempt：豁免唯一入口（fn-ladder 横向能力）

一切门禁豁免的规则、档位与记账集中在此，**不与其他命令混杂**。其他技能的门一律执行"**无有效豁免行 = 不得跳过**"。口头提出豁免只是**触发器**，不是豁免本身；**无记账 = 无豁免**。

## 铁律（永不可豁免）

豁免免的是"停下来等人"和"审查门"，**永远不免"证据"**：核验绿了才改、读回断言、失败不记账、无证据 = 该步未做——四条对豁免免疫，冲刺与连做期间照跑照贴。不可逆动作（外发/删除/覆盖）不因豁免放宽，仍需明批。

## 流程（四步强制序列，按序逐条执行、每步留证）

1. **宣告**：用户**口头**提出豁免（"免审吧""剩下的不用等我"等）时，代理的第一动作是固定宣告语 **"开始执行 /fn-exempt"**——先宣告、后动手；**禁止静默补账，禁止不宣告先干活**。用户直接调用本技能的免此步（调用即宣告）。
2. **定类型与对象**（五类，写明作用对象"技能·门"，**不跨技能继承**）：

   | 类型 | 免什么 | 出处 |
   |---|---|---|
   | 免审 | 批间门三轴审查（批间报告仍须报文档与 tracker 同步情况） | fn-implement 批间门 |
   | 冲刺 | 门口/批间门停等（门不停人，证据照贴） | fn-implement / fn-analyze |
   | 预授权连做 | 剩余批次的门停等 | fn-implement 批间门 |
   | 接管 commit | 自动 commit（git 第二真值退化为用户自管） | fn-implement 批内循环 |
   | analyze 冲刺 | fn-analyze 流水步间免确认 | fn-analyze |

3. **定档位**：**单门一次**（默认）/ **本批** / **剩余全部**——后两档必须用户显式声明（字面"剩下的批次不用等我"才够，模糊的"继续"只解锁当前门）。不自动续期。
4. **记账**：tracker 豁免节追加豁免行 + `fn-commit.sh` 落 JOURNAL 痕，**读回贴出改后行**（脚本打印成功不算写入证据）。无记账 = 无豁免。

```markdown
- X<n>: <类型> | 范围: 单门/本批/剩余全部 | 对象: <技能·门> | 原因 | 剩余: N | 状态: active/consumed
```

## 用后处理

- 每个被放行的门在 tracker 对应门行注明引用（如"门放行: X2"）——事后可还原每个门的处置。
- 额度用完即把状态改 `consumed` 并读回；范围外、到期、consumed 后照常停。
- **撤销**：用户明说撤销 → 状态改 `consumed` + 一行撤销说明，读回；撤销后不得再凭该行放行。**consumed 后有撤销说明行 = 主动撤销；无说明行 = 额度用尽**——审计按此区分。

## 出口

**出门前自检（逐条对照，缺一不许出门）**：宣告语说过（口头触发时）？类型与对象写明？档位经用户确认（"剩余全部"须有显式声明记录）？豁免行已写 tracker 并读回？JOURNAL 已落痕？——任一缺 = 回去补做。

豁免生效后**不设停**（免停即豁免的全部意义），但必须向用户报告一行生效范围（"豁免 X<n> 生效：类型 / 范围 / 剩余"）并按其范围继续原流程；**范围外的门照常停**。误触本技能（并无豁免需求）→ 停，说明无豁免发生、回原流程。

## 红旗（出现即停）

| 念头 | 现实 |
|---|---|
| "用户都说免审了，直接跳过吧" | 口头只是触发器：先宣告"开始执行 /fn-exempt"、后记账；无豁免行 = 不得跳门 |
| "先放行，回头再补记账" | 无记账 = 无豁免；静默补账 = 审计无痕的私自豁免 |
| "一次豁免，后面都好说" | 档位就是额度：单门/本批/剩余全部各自独立，用完 consumed，不自动续期 |
| "冲刺都豁了，证据缓缓" | 证据类纪律永不可豁免，照跑照贴 |
| "这个门顺手一起免了吧" | 豁免不跨技能继承，对象必须写明 |
