# fn-quick：轻量臂（fn-ladder 快车道）

单函数/参数级小手术的快通道：**判据先行的纪律不降，仪式降**——不建责任全树、无批间门，但验收一条先行、核验输出必贴、fn-commit 必落痕。

## 进入检查（防超载）

目标 ≤1 个函数或纯参数/配置级改动、预计 ≤30 分钟。超出（涉及多函数 / 新结构 / 需求不清）→ 停，指回 `/fn-grill`（全套五阶段），不许硬撑轻量臂。

## 三步

1. **快问**（微型 grill，两句话经用户确认即开工）：**目的一句话 + 验收一条**（优先"命令 + 期望输出"，否则可观察判据三要素）。验收方式不许实现时现编。
2. **实现 + 核验**：直接改；跑验收命令、**贴输出**，绿了才称完成。两轮不过 → 停，考虑升 `/fn-grill` 或转 `/fn-brainstorm`。
3. **落痕**：任务工作目录下运行插件根 `scripts/fn-commit.sh "<quick> <摘要>" "<核验结果>"`——JOURNAL 行 + commit + push 一气呵成。

## 出口

完成后**停**，显式提示两项：**继续下一个轻量臂（`/fn-quick`）**，或**升全套（`/fn-grill`）**——改动比预想大时；用户未显式选择前不推进。

## 红旗（出现即停）

| 念头 | 现实 |
|---|---|
| "改着改着牵出第三个函数了" | 超载即升全套，轻量臂不硬撑 |
| "验收回头补" | 判据先行是唯一不降的纪律 |
| "这么小不用 commit 了吧" | fn-commit 落痕是轻量臂的唯一仪式 |
